# ESP32-S3 4 线 PWM 风扇接入规范

版本:V1.0 | 适用固件:`fan_ctrl` 组件 | 关联:[DESIGN §13](../DESIGN.md)、[MQTT_PROTOCOL §2.1/§3.1/§4.3](../MQTT_PROTOCOL.md)

## 1. 概述

为温控设备接入 1 只 4 线 PWM 调速风扇,提供:

- **调速**:PWM 占空比 0~100%(手动,经 MQTT 下发);
- **测速**:TACH 转速脉冲计数,实时上报 RPM;
- **在线监测**:堵转检测(`stall`)与边沿触发告警事件。

> **电气安全总则(先读)**
> 1. 风扇由**外部 12 V 电源**供电,**严禁**从 ESP32 开发板取电;
> 2. 外部电源 GND 必须与开发板 GND **共地**;
> 3. ESP32-S3 GPIO **不耐 5 V**——TACH 上拉电阻只能接 **3.3 V**,**严禁接 5 V**;
> 4. 风扇 PWM 输入内部可能上拉至 5 V,建议经电平转换驱动(见 §3.2)。

## 2. 引脚定义

| 信号 | GPIO | Kconfig 项 | 方向 | 说明 |
|------|------|-----------|------|------|
| PWM 调速 | **GPIO5** | `APP_FAN_PWM_GPIO` | 输出 | LEDC 25 kHz,10-bit;配 -1 可整体禁用风扇功能 |
| TACH 转速 | **GPIO6** | `APP_FAN_TACH_GPIO` | 输入 | PCNT 脉冲计数,2 脉冲/转,1 s 测速窗口;配 -1 仅禁测速 |

## 3. 接线方式

### 3.1 4 线风扇引脚(标准 Intel 4-wire 定义)

风扇线色为常见惯例,以**连接器丝印/数据手册**为准:

| 风扇引脚 | 线色(惯例) | 信号 | 接法 |
|----------|------------|------|------|
| 1 | 黑 | G· ND | 外部 12 V 电源 GND,**并与开发板 GND 相连(共地)** |
| 2 | 黄 | +12 V | 外部 12 V 电源 +12 V(**不接开发板**) |
| 3 | 绿 | TACH(开漏转速脉冲) | → GPIO6,并经 **10 kΩ 上拉电阻接 3.3 V** |
| 4 | 蓝 | PWM(开漏调速输入) | → GPIO5(经 1 kΩ 串联电阻直接驱动,或经 §3.2 电平转换) |

```
              外部 12 V 电源
              +12V ---------> 风扇 pin2 (黄, +12V)
              GND  ---------> 风扇 pin1 (黑, GND)
                               |
                               +-----> 开发板 GND(共地, 必接)

   开发板 3V3 ---[10kΩ]---+--- 风扇 pin3 (绿, TACH) ----> GPIO6
                          |
   开发板 GPIO5 ---[1kΩ]--+--- 风扇 pin4 (蓝, PWM)   (或经电平转换, 见 §3.2)
```

### 3.2 PWM 电平转换(推荐)

风扇 PWM 输入内部通常上拉至 5 V;若直接连接,GPIO5 可能经串联电阻承受少量
灌电流(1 kΩ 限流下一般可接受)。**推荐做法**是 NPN 三极管或 N-MOSFET 开漏转换:

```
   GPIO5 ---[1kΩ]---+--- NPN 基极 (或 N-MOS 栅极)
                    |
                   [10kΩ] 下拉
   12V侧/风扇PWM <--- 集电极/漏极 (开漏, 利用风扇内部上拉至 5V)
   GND ------------ 发射极/源极 (共地)
```

不接电平转换时,**必须**保留 GPIO5 与风扇 PWM 之间的 1 kΩ 串联电阻。

### 3.3 5 V 风扇变体

5 V 风扇(笔记本型,常见 0.4 A)只需将外部电源改为 **5 V**,接法完全相同;
注意 TACH 上拉**仍接 3.3 V**(上拉电压与风扇供电电压无关,取决于 GPIO 电平)。
2 线风扇无调速/测速、3 线风扇仅测速无 PWM,均不在本规范范围。

## 4. 功能行为

| 项目 | 值 |
|------|-----|
| PWM 频率 | 25 kHz(规范推荐值,超声频段无啸叫) |
| 占空比 | 0~100%,0% = 停转(状态 `off`) |
| 测速窗口 | 1 s PCNT 计数,`rpm = 脉冲数 × 60 / 2` |
| 堵转判定 | 占空比 >0 且持续 3 s 无转速脉冲 → `stall` |
| 启动宽限 | 占空比上调后 3 s 内 `rpm=0` 仍报 `ok` |
| 停机惯性宽限 | `duty=0` 后 3 s 内余转仍报 `off`;超时仍旋转 → `overrun` |
| 失控空转 | `duty=0` 但持续 3 s 以上 `rpm>0` → `overrun`(PWM 未生效,见 §5) |
| 控制方式 | **仅手动**(MQTT `fans/0/command`),不与温控自动联动 |
| 掉电行为 | 占空比不持久化,重启恢复 Kconfig 初始值(默认 0%) |
| 告警 | 进入 `stall` 瞬间发布 `fan_stall` 事件(边沿触发,不重发);进入 `overrun` 打 ERROR 日志(边沿,不发事件) |

## 5. 故障排查

| 现象 | 检查 |
|------|------|
| RPM 恒为 0,状态 `stall` | TACH 上拉是否接 3.3 V;共地是否可靠;转速线是否接对(绿) |
| RPM 恒为 0,状态 `off` | 占空比是否为 0;PWM 线(蓝)是否接对;是否为 3 线风扇 |
| **满速旋转但 `duty=0`/`status:"off"` 或 `overrun`** | **PWM 线(蓝)未接或接到错误引脚;风扇实为 3 线(仅测速无调速);PWM 输入悬空导致部分风扇默认全速**。固件在 3 s 惯性宽限后报 `overrun` 而非 `off`,但软件无法代替正确接线 |
| 占空比设不上去 | 是否向 `fans/0/command` 发布;`fan` 字段须为 0 |
| 风扇不转且无告警 | 12 V 供电是否正常;风扇是否缺外部供电 |
